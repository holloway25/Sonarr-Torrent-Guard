## Darker revision prompt

Edit target: the supplied Sonarr Torrent Guard application icon. Make it only
slightly darker overall, approximately 15 percent lower brightness, with less
intense cyan highlights. Preserve the exact existing shield silhouette, radar
rings, radar sweep, three dots, play triangle, layout, proportions, blue/cyan
colour identity, crisp edges and subtle depth. Keep it readable at small Unraid
icon sizes. Preserve genuine background transparency and existing padding.
No new elements, text or redesign; this is a restrained brightness adjustment only.

## Generation prompt

Use case: logo-brand. Asset type: original square application icon for Sonarr
Torrent Guard, used in Unraid's Docker container list and a future web UI. Create
one polished, clean icon: a protective shield enclosing a stylised sonar/radar
sweep and a small media play triangle, integrated as one strong silhouette.
Modern restrained app-icon design, crisp thick forms, high contrast, recognisable
at 48 pixels, balanced and centred with generous clear edge padding. Subtle depth
is fine but avoid fine detailing. Genuine transparent background outside the
icon. No text, initials, labels, personal information, watermark, Docker whale,
or copied Sonarr logo. Single icon only, not a presentation sheet or mockup.
